GLB 3D Editor — DECA 3D Viewer
================================

Editor 3D professionale per file GLB/GLTF con intelligenza artificiale integrata,
sviluppato per DECA S.r.l. Permette di visualizzare, assemblare e gestire modelli 3D
di alimentatori vibranti, nastri trasportatori, tramogge, cappe afoniche e componenti
industriali per l'automazione direttamente al cliente.

L'esperienza e' rivolta al cliente finale: dalla homepage sceglie un prodotto
configurabile dal catalogo, lo apre nell'editor 3D, puo' chiedere informazioni tecniche
a DecAI in linguaggio naturale e con un click invia una richiesta di preventivo ai
commerciali DECA. Il tutto con tema visivo corporate DECA (rosso #c41e3a, blu #004a99,
bianco, font Inter).

Il cuore del progetto e' DecAI, l'assistente AI aziendale di DECA. Si tratta di un
modello linguistico (LLM) basato su Meta Llama, addestrato (fine-tuning) sui dati
tecnici e sul catalogo prodotti DECA per rispondere a domande specifiche di ingegneria
meccanica e controllare la scena 3D tramite linguaggio naturale.

Il modello gira in locale sulla GPU NVIDIA RTX 4000 Ada (20 GB VRAM) di questo
computer, servito tramite LM Studio sulla porta 1234. Non dipende da servizi cloud:
l'inferenza avviene interamente on-premise, garantendo riservatezza dei dati aziendali
e tempi di risposta rapidi. Il fine-tuning e' stato eseguito con Unsloth + QLoRA
in WSL2 (Ubuntu 22.04) sulla stessa GPU.

L'editor web (Three.js) permette di caricare, manipolare ed esportare modelli 3D
direttamente nel browser, con supporto per trasformazioni, materiali PBR, edge lines
stile SolidWorks, strumenti di misura, accoppiamento superfici e libreria prodotti navigabile.

Lo script CLI permette di modificare file GLB da riga di comando: scala, rotazione,
traslazione, colori, merge di mesh e altro, senza bisogno di software 3D.

Il progetto e' deployato online tramite Firebase Hosting (progetto: glb-3d-editor).
  - https://glb-3d-editor.web.app
  - https://glb-3d-editor.firebaseapp.com


Funzionalita' principali
-------------------------
- Caricamento GLB/GLTF via file picker o drag & drop
- Esportazione multi-formato: GLB, GLTF, OBJ, STL
- Trasformazioni: sposta (W), ruota (E), scala (R) con snap configurabile
- Undo/Redo (Ctrl+Z / Ctrl+Y)
- Misura distanza 2 punti (M)
- Quotatura tecnica (Q): bounding box wireframe, quote ingombri in mm, sfondo neutro, linee di estensione e frecce
- Accoppiamento superfici (mate a 2 fasi: sorgente + destinazione)
- Duplicazione e specchiatura oggetti (X, Y, Z)
- Materiali PBR: colore, emissivo, metallicita', rugosita', opacita', wireframe
- Luci e ambiente: sfondo, luce ambiente, luce direzionale, griglia, assi
- Bordi stile SolidWorks con angolo configurabile
- Visualizzatore PDF integrato (disegni tecnici)
- Visualizzatore XLS integrato (distinte base, via SheetJS)
- Autenticazione Google / email (Firebase Auth)
- Rendering markdown nei messaggi DecAI (headings, liste, code blocks, blockquote)
- Sistema di annotazioni e feedback con pin sulla scena 3D
- Badge di sentiment (positivo/problema/suggerimento) e sorgente (AI/locale)
- Feedback thumbs up/down sui messaggi del chatbot
- Toast notification per caricamento modelli
- Richiesta preventivo end-to-end dall'editor alla mail commerciale DECA
- Viewer 3D condivisibile (viewer.html) via link pubblico, con preview Open Graph
- Tutorial video auto-loop in homepage (6 scene animate, ~40 secondi) che mostra
  dal catalogo all'invio della richiesta preventivo
- Analytics dashboard custom con pannelli Richieste Preventivo, Visite, Visitatori,
  Funnel, Sentiment, Feature Requests. Accesso riservato all'email admin
  (Google Sign-In + regole Firestore isAdmin())
- Modal di autenticazione nella home con Google Sign-In e link-email passwordless
  (Firebase Auth). Pulsante "Accedi / Registrati" nell'header; avatar utente
  cliccabile per logout dopo accesso


Libreria prodotti
-----------------
Navigazione gerarchica a cartelle basata su db_tree.json, con breadcrumb e ricerca.
I modelli sono organizzati in due categorie principali:
  - CMP: Componenti (organizzati per famiglia/tipo)
  - PRD: Prodotti (organizzati per codice prodotto)

Ogni modello puo' avere associati:
  - File .glb (modello 3D)
  - File .pdf (disegno tecnico), indicizzati in drawings_index.json
  - File .xls (distinta base / BOM), indicizzati in distinte_index.json

Il catalogo unificato (catalog.json) mappa ogni voce a nome, codice, glb, pdf, xls.
Il database BOM (bom_database.json) contiene le distinte base estratte dagli XLS.


DecAI — Assistente AI aziendale di DECA S.r.l.
------------------------------------------------
DecAI e' il cuore intelligente dell'applicazione: un LLM basato su Meta Llama,
fine-tuned con Unsloth + QLoRA sui dati tecnici DECA (catalogo prodotti, distinte
base, nomenclatura componenti, specifiche di ingegneria meccanica).

Architettura AI:
  - Modello base: Meta Llama 3 (8B parametri, quantizzato Q4_K_M per efficienza)
  - Fine-tuning: QLoRA via Unsloth su WSL2 Ubuntu 22.04
  - Training data: catalogo DECA, distinte base XLS, nomenclatura prodotti
  - Inferenza: GPU locale NVIDIA RTX 4000 Ada (20 GB VRAM), servita da LM Studio
  - Nessuna dipendenza cloud: dati aziendali mai esposti a servizi esterni
  - System prompt specializzato: risponde in italiano, produce azioni JSON
    per controllare la scena 3D (spostare, ruotare, colorare, caricare modelli)

Chatbot in basso a sinistra con due modalita':
  - Linguaggio naturale via LLM (GPU locale, porta 1234)
  - Comandi strutturati (fallback sempre disponibile senza LLM)

Backend configurabile: LM Studio locale, Cloudflare Tunnel, server DECAAI custom.
Indicatore di stato connessione con feedback colore (verde = LLM attivo).

System prompt potenziato con:
  - Informazioni ufficiali DECA S.r.l. (descrizione, sito https://www.decasrl.biz)
  - Contatti aziendali (+39 0341 63 20 80)
  - Guardrail piu' rigidi (niente URL inventati, niente nomi prodotto fabbricati)
  - Regola esplicita: DECA produce molti prodotti diversificati (non solo una categoria)

Comandi disponibili:
  Ricerca e libreria:
    [nome prodotto]            Cerca per descrizione nella libreria PRD
    aggiungi [nome]            Carica un modello .glb dalla libreria
    disegno [nome]             Apre il disegno PDF associato
    distinta [nome]            Apre la distinta Excel associata

  Trasformazioni:
    seleziona [nome]           Seleziona un oggetto in scena
    sposta x y z               Sposta l'oggetto selezionato
    ruota x y z                Ruota in gradi
    colore [colore]            Cambia colore (nome o #hex)
    accoppia                   Avvia il modo accoppiamento facce
    rimuovi [nome]             Rimuovi un oggetto dalla scena
    duplica [nome]             Duplica un oggetto
    sistema                    Disponi tutti gli oggetti in griglia ordinata

  Database:
    search_bom [codice]        Cerca nella distinta base
    search_drawing [codice]    Cerca disegni tecnici
    search_distinta [codice]   Cerca fogli di assemblaggio

  aiuto                        Lista comandi disponibili

Azioni JSON restituite dall'LLM: select, move, rotate, color, load, remove,
arrange, mate, search_bom, search_drawing, search_distinta, replace.

API per automazione (serve_editor.py)
--------------------------------------
Server locale (porta 3000) con API REST per controllo programmatico della scena:
  - POST /api/commands: add_primitive, set_transform, set_material, delete,
    select, fit_camera, clear
  - GET /api/scene-info: stato della scena (oggetti, posizioni, selezione)
  - Primitive supportate: box, sphere, cylinder, cone, torus, plane, capsule
  - Polling automatico ogni 3 secondi per comandi in coda
  - Proxy verso LM Studio per richieste AI


Scorciatoie tastiera
---------------------
  W              Modalita' traslazione
  E              Modalita' rotazione
  R              Modalita' scala
  M              Strumento misura
  ESC            Annulla operazione (misura, accoppiamento)
  Delete/Backsp  Elimina oggetto selezionato
  Ctrl+Z         Annulla
  Ctrl+Y         Ripristina
