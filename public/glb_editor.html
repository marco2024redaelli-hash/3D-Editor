Come attivare DecAI

Prerequisiti

DecAI gira sul PC UFFTEC10 (Marco Redaelli) tramite WSL2 Ubuntu. Servono:

  • Terminale Ubuntu/WSL aperto
  • Ambiente Python decai-env
  • Modello addestrato nella cartella lora_model/

Avvio del server AI

1
Apri il terminale Ubuntu e vai nella cartella del progetto:
cd ~/decai-finetune
2
Attiva l'ambiente Python:
source ~/decai-env/bin/activate
3
Avvia il server FastAPI (porta 8000):
python app_server.py

Esporre il server tramite Cloudflare Tunnel

4
Apri un secondo terminale Ubuntu e lancia il tunnel:
cd ~/decai-finetune
./cloudflared tunnel --url http://localhost:8000
5
Copia il link generato dal tunnel (es. https://xxxxx.trycloudflare.com)
Nota: Ogni volta che rilanci il server, il link del tunnel cambia. Dovrai aggiornarlo nel passaggio successivo.

Collegare DecAI al sito

6
Nell'header della chat, clicca sull'icona ⚙ (ingranaggio)
7
Incolla l'URL del tunnel Cloudflare e conferma
8
Il pallino di stato diventa verde = DecAI connessa e pronta

Riaddestrare il modello

Se vuoi aggiornare il modello con nuovi dati di training:

1
Modifica il dataset in TRAINING VARI/TrainingUfficiale_integrato.json
2
Lancia il training:
cd ~/decai-finetune
source ~/decai-env/bin/activate
python train.py
3
Dopo il training, esegui la pipeline post-training (merge + GGUF + Ollama):
python post_training.py
Monitoraggio: Durante il training osserva la Loss nel terminale. Deve scendere gradualmente (es. 2.0 → 1.2 → 0.8). Se scende troppo verso 0 c'e' overfitting.

Architettura

Modello base: LLama 3 8B (4-bit via Unsloth)
Tecnica: LoRA (r=32, alpha=64)
Training: 10 epoche, SFTTrainer, AdamW 8-bit
Formato prompt: Alpaca-style (Sistema/Domanda/Risposta)
HuggingFace: Marco20262026/DECAAI-merged
